# 图床插件

在「设置 → MCP 与图片存储 → 图床」展开配置，插件 ID 为 `markvault.image-hosting`。默认停用，需明确同意上传并选择用途。它是随主程序分发的原生插件，不依赖 Deno。

## S3 / Cloudflare R2 / MinIO

插件详情默认选择 S3 兼容存储。填写已创建的桶和专用访问密钥，不需要公开桶权限，也不会自动创建桶或修改 ACL。

| 服务 | API 端点示例 | 区域 | 寻址方式 |
| --- | --- | --- | --- |
| AWS S3 | https://s3.eu-west-1.amazonaws.com | 桶的实际区域，例如 eu-west-1 | 支持路径式与虚拟主机式；含点桶名使用路径式 |
| Cloudflare R2 | https://账户标识.r2.cloudflarestorage.com | auto | 路径式 |
| MinIO | https://minio.example.com:9000 | 通常 us-east-1，以部署配置为准 | 路径式 |

API 端点中不包含桶名、路径或查询参数。对象前缀可填写 markvault 或 markvault/images，仅接受字母、数字、下划线、短横线和分隔斜杠。图片使用随机对象名，避免覆盖已有对象。

Access Key ID 和 Secret Access Key 使用独立字段输入，二者整体加密保存，不放进插件 JSON 配置，不回传给浏览器。留空保留已有密钥，替换时需同时填写两项。密钥至少需要所选桶/前缀的对象上传、读取权限（s3:PutObject 和 s3:GetObject）；当前不请求列桶、删对象或修改 ACL 权限。首版仅支持静态密钥，不支持临时 STS session token、IAM 角色自动取凭据或 AWS KMS 专用配置。

**私有桶：**“公开图片 / CDN 基础地址”留空。每次上传与读取使用 AWS Signature V4，本站仍向浏览器提供有权限检查的签名图片链接，不持久化会过期的 S3 预签名 URL。

**公开桶或 CDN：**填写对应桶根目录的 HTTPS 基础地址，例如 https://images.example.com。宿主自动追加对象前缀和文件名；公开读取不携带 S3 凭据。上传后必须能从该地址立即匿名读取，否则保留本地副本。

已有私有桶图片保存上传时的配置与加密读取凭据，以保证修改当前图床配置、删除新上传凭据或停用插件后仍可访问。删除对应本站图片会清理这些读取凭据；在存储服务侧撤销旧密钥会使使用该密钥的旧图片不可读，当前不会自动迁移旧图片或重写其凭据。应先规划旧对象迁移再撤销密钥。

## 通用 HTTP 图床

仍支持使用 multipart/form-data 上传、返回 JSON 图片 URL 的图床。旧配置没有 backend 字段时继续按 HTTP 解释。

| 设置 | 示例 | 含义 |
| --- | --- | --- |
| 上传地址 | https://images.example.com/api/upload | 固定 HTTPS 地址，不接受查询串或 URL 内凭据 |
| 文件字段名 | file | 图床接口要求的 multipart 文件字段 |
| URL 路径 | data.url | 从响应提取图片地址；支持 data.0.url 这样的数组路径 |
| 认证请求头 | Authorization / X-API-Key | 留空表示无需认证；只支持 Authorization 或 X-* |
| 认证值 | 图床要求的完整请求头值 | 使用 Bearer 时填写完整前缀与密钥；单独加密保存 |

返回的图片 URL 应长期可匿名读取，上传认证不会发送给图片地址。切换上传来源或后端后旧的上传凭据自动清除。暂不支持 OAuth、额外 multipart 字段或 HTTP 图床的私有下载认证。

## 图片用途

每项独立选择：

- **网站截图**：扩展通过现有截图接口保存的 PNG、JPEG、WebP。
- **网页快照内的图片**：通过 images 数组保存的快照资源；快照 HTML 留在本站，沙箱与签名改写保持原逻辑。
- **书签封面**：新增或编辑书签时明确保存的 HTTPS 封面地址，先读取再转存。
- **网站图标**：新增或编辑书签时明确保存的 HTTPS favicon 地址；浏览器临时使用的 Google favicon 不会自动转存。
- **自定义默认图**：在插件详情上传的账号默认图。当登录账号的书签没有可用封面或图标时显示，不修改书签自身字段。最大 2 MiB，支持 PNG、JPEG、WebP；未勾选该用途时保存在本地。匿名分享使用原有默认展示。

仅处理新保存的图片，不自动迁移历史数据。取消某项后，新截图、快照图片或默认图保存在本地，新封面和图标保留原地址。停用插件不会使已保存的图片失效。主站沿用既有截图、快照及书签接口，浏览器扩展不需要变更。

## 保存与访问

图片先在本站完成持久化，再在数据库事务外上传。成功获取可读图片后保存图床映射并移除本地副本；失败、超时或配置变化时保留原图，插件详情显示失败信息。一次截图或快照上传批次最多等待 30 秒；尚未处理的图片保留本地，不会自动重试可能已经成功的上传。

图片通过本站签名接口代理读取，继续检查账号归属、书签状态与分享权限，禁止把上传密钥或图床原始地址放入快照。图床下载限制为 10 MiB，只接受识别为图片的内容，并保留图片 sandbox CSP。默认阻止私网与重定向；管理员如需自托管图床，使用 `MARKVAULT_PLUGIN_PRIVATE_TARGETS` 逐项允许完整 HTTPS 来源，上传源和图片源需分别配置。虚拟主机式 S3 需要放行包含桶名前缀的实际来源。

图片会发送给所配置的图床，公开图床或 CDN 的原始 URL 可能公开可访问；私有桶保持签名访问。删除本站图片会清理本站引用和本地文件；当前两类后端均不自动删除远端对象，应在图床侧管理保留期限或手动清理。图床对象仍按原文件逻辑大小计入实例配额。备份数据库仅包含图床映射，图床文件需单独备份。

## 验证

`TestImageHostingPurposesFallbackAndAccess` 使用本地 HTTPS 图床验证五类用途、未选中不上传、密钥隔离、签名代理、跨账号拒绝、快照 CSP、上传失败回退、停用后读取和删除引用清理。

`TestImageHostingSettingsBoundaries` 验证配置校验、凭据来源绑定、API Key 不可修改设置和内网下载拒绝。前端同时执行类型检查、ESLint、Vitest 与生产构建。

S3 专项测试使用独立签名向量、三类端点寻址测试，以及进程内 S3 模拟传输，覆盖 PUT/GET 签名校验、私有桶读取、公开 CDN 不带密钥、旧配置读取、非法对象路径拒绝、密钥加密与本地回退。尚未使用真实 S3/R2/MinIO 账号执行远端验收。
