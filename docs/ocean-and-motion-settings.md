# 海洋彩蛋与动效设置

「设置 → 动效」只提供一个界面动画总开关，按钮、卡片、列表及页面切换统一使用标准动效。速度、强度、单项开关、重置与演示面板已移除。旧数据库字段保留用于兼容旧客户端，新界面不再读取单项动效值；关闭总开关或系统启用「减少动态效果」时停止动画，海洋背景保留静态画面。

海洋彩蛋支持关闭、鲨鱼、海豚及混合四种样式，并提供两种保存方式：

- **保存到账号**：选择样式后点击「保存设置」。同一账号在其他浏览器登录、刷新或重新聚焦页面时读取相同设置。服务器确认成功后才提示保存成功；保存失败时保留草稿，离开设置页则恢复已保存的账号样式。
- **跟随浏览器**：样式立即保存到当前浏览器的 `theme-storage`。保存这种模式后，每个浏览器使用各自的本地选择。此处不是跟随浏览器的深浅色主题或「减少动态效果」开关。

两种模式分别保存样式，切换模式不会覆盖另一个模式的选择。默认使用浏览器模式，升级后已有本地选择继续生效。账号海洋偏好只作用于登录后的个人页面，不随公开分享接口输出；公开页面继续使用访客浏览器的本地选择。

鱼群进度在当前标签页内保留：切换页面或刷新后，恢复原来的位置、速度、游动方向与摆尾相位；切换白天／夜晚只调整配色。关闭界面动效或启用系统「减少动态效果」时原地暂停，重新开启后继续游动。鲨鱼、海豚及混合样式各自保留进度。页面卸载或隐藏时将快照保存到 `sessionStorage`，不逐帧写入，也不上传到账号；关闭标签页后会话进度结束。浏览器禁用存储时，站内切页仍可从内存恢复，但刷新会重新生成鱼群。

服务启动时自动应用 `0126_ocean_preferences.sql`，无需额外环境变量。`GET/PATCH /api/v1/preferences` 新增 `ocean_background_scope`（`browser` / `account`）和 `ocean_background`（`off` / `sharks` / `dolphins` / `mixed`），共享契约见 `shared/ocean-preferences.ts`。
