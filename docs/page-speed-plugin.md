# 页面加载速度插件

在“设置 → 图表统计”开启“页面加载速度”（markvault.page-speed）。默认关闭，无需填写配置。启用后在主站页头右下沿显示耗时徽标，点击展开详情；手机端只显示图标与读数，避免挤压导航按钮。

- **页面加载**：使用 Navigation Timing，从浏览器导航开始到 loadEventEnd；详情展示首字节响应、DOM 就绪和首次内容绘制。缓存、网络、设备与浏览器环境都会影响结果，不能将其视为纯服务器响应速度。缺失指标显示“—”。
- **页面切换**：从 React Router 路由变化到页面提交后的下一次绘制机会，包含懒加载模块等待；不包括后续异步数据请求、图片或动画。地址参数变化会重新测量，纯锚点跳转不重新测量。
- **中途启用**：刷新后的首次页面可回读浏览器导航记录；若已经发生过站内导航，则等待下一次切页或刷新，避免将插件挂载时间误报成页面加载时间。
- **暂停与退出**：测量过程中切入后台会丢弃结果，30 秒仍未完成时显示“未完成”。停用插件、进入安全模式或退出登录后不显示徽标并释放计时器和监听器。

计时数据仅保存在当前页面内存，不保存历史、不上传，也不收集页面内容。启停状态沿用现有账号插件设置，管理员全实例停用同样生效。匿名公开分享页不加载账号插件目录，因此不显示此插件。
