# 公开分享页点击统计

公开书签页中打开书签、点击网址或选中标签，都会计入分享者现有的累计次数、点击趋势和排行榜。访客无需登录；已登录的访客也不会把这些点击记到自己的账号。

- 书签的卡片、列表、极简、标题和收藏卡视图均支持记录；网址链接的普通点击和鼠标中键打开均记录一次。
- 标签侧栏、移动端标签抽屉及书签上的标签使用相同口径：选中时记一次，取消选择、清空筛选和页面加载不计数。
- 点击统计异步发送，失败不影响打开网页或标签筛选。界面热度只在接口成功后更新。
- 点击合并进入已有 `bookmark_click_events`、`tag_click_events`，无需数据库迁移。暂不区分私有页与公开页来源，也不按访客去重，因此表示点击次数而非访客人数。
- 历史上未记录的公开点击无法补录；升级后产生的点击开始计入。

## 接口与权限

匿名接口为 `POST /api/public/{slug}/bookmarks/{id}/click` 和 `POST /api/public/{slug}/tags/{id}/click`，成功返回 204，不返回所有者账号或资源详情。

服务端在同一事务中确认分享仍然启用、资源归属正确、书签未删除且公开，再更新累计值和明细。标签必须未删除，并且至少关联一个仍公开且未删除的书签。关闭分享、更换别名、转为私有或删除资源后，旧页面发出的点击请求会返回 404。

公开点击按服务器识别的访客 IP 共享每分钟 240 次额度，限流键仅保存 IP 哈希，书签和标签共用额度；分享者的登录点击额度独立计算。超过额度返回 429。代理部署继续使用现有的可信代理配置，不接受未受信任的 `X-Forwarded-For` 覆盖访客地址。
