Self-hosted · Single container · Source available

Keep your bookmarks, tab groups and web page snapshots on your own server

MarkVault is a self-hosted bookmark manager. One Go program serves the REST API, the SQLite database, local object storage and the web interface, so a single container is enough. It needs no external database or object storage service.

Quick start API docs View on GitHub

Runs in one container

A single Go program includes the API, SQLite, object storage and the frontend. It does not depend on Cloudflare, an external database or an object storage service.

Your data stays with you

All data lives in one directory. Stop the service and copy the directory for a full backup. JSON import and export are also available.

Browser extension

A Chromium extension connects to your own instance to save pages, tab groups and versioned web page snapshots.

An API for AI agents

API keys with fine-grained permissions, a stable REST API and an MCP endpoint. Write actions need confirmation.

Bookmarks and tags

Save, organise and find things again

Search, filters, pinning, batch organising, click counts and a trash, all on one page.

  • Search and filters: search titles, descriptions and URLs by keyword, and combine several tags to narrow the results.
  • Pinning and batch organising: pin, archive, retag or delete many selected bookmarks in one step.
  • Trash: deleted bookmarks go to the trash first and can be restored.
  • Web page snapshots: with the extension, save versioned snapshots of a bookmarked page, so it stays readable after the original goes offline.

Switch between light and dark mode at any time, or follow the system setting. The interface is available in English and Simplified Chinese; the screenshots on this page show the Chinese interface.

Views

The same bookmarks, seen another way

Besides the card, list, minimal and title views, the gallery, timeline, site groups and focus views ship as built-in plugins. Turn them on under Settings → Layouts & views.

Interface themes

Five interface themes, plus an ASCII ocean

Themes, colors and page layouts are switched under Settings → Interface & colors. Background animation is set under Animation & backgrounds.

Page layouts

Rearrange the whole page

A view replaces only the bookmark list. A page layout takes over the whole page: where the tags, toolbar, list and side panel go. The home page has five layouts: top bar, start page, three panes, tag board and infinite canvas.

Tab groups

Put a window of tabs away and open it again later

Save and organise sets of pages, with groups, to-dos and restore.

  • Groups and folders: tab groups can go into folders for layered organisation.
  • To-dos: mark tabs you have not dealt with yet as to-dos and review them in one place.
  • Trash: deleted groups can be restored.
  • Sharing: create a share link for a single group, with an optional expiry date.

Statistics

See which bookmarks you actually use

  • Click trends, rankings and time-of-day distribution for bookmarks and tags.
  • View by day, week or month, pick your own date range, or look at a single tag.
  • A separate Agent & MCP page shows the number of external calls, their success rate and latency. Only call metadata is recorded; request parameters and returned content are not stored.

Public sharing

Turn a selection of bookmarks into a public page

Mark bookmarks as public and they appear on your share page. You choose the link suffix, page title and description. Once sharing is turned off, the share page is no longer accessible.

Agent and MCP

Let AI read and write your bookmarks, with writes confirmed by you

Every instance includes an integration guide page. External agents can connect through the Skill, the REST API or MCP. Parameters, permissions and examples are in the API docs.

  • Fine-grained API keys: choose the read-only, basic or full template to suit the purpose, or grant permissions one by one. Keys can be revoked and given an expiry time.
  • REST API: /api/v1/agent/* provides bookmark, tag and search endpoints, with an OpenAPI 3.1 contract.
  • MCP: POST /api/mcp provides 13 built-in tools. The tool list is filtered by the key's permissions, and write tools must be called with confirm: true.
  • In-app agent: once a model is configured, query and organise bookmarks in natural language. Write actions show a confirmation card first, and no data changes until you confirm.

Plugins

Switch built-in features on as needed, and install third-party plugins

Built-in features such as interface themes, color palettes, page layouts, the various views, the ocean background, image hosting, passkeys and external MCP connections are switched on and configured in the matching section of the settings page.

Third-party plugins are managed under Settings → Custom plugins. Administrators can install them from the offline catalog, a ZIP file or a pinned GitHub Release asset; each user then grants permissions separately. If a plugin misbehaves, opening /plugins?safe=1 skips optional plugins so that it can be turned off.

Data and backup

One directory holds all the data

  • The SQLite database, stored objects (snapshots, images, screenshots) and the instance keys are all in the same data directory.
  • Full backup: stop the service and copy the whole directory.
  • JSON import and export: export bookmarks, tags and tab groups, compatible with legacy TMarks JSON. It contains business data only, without snapshot files, images or instance keys, and cannot restore a full instance.
  • The number of snapshots to keep is adjusted in the settings. The total file storage limit is set by the deployment option STORAGE_MAX_TOTAL_BYTES and defaults to about 7 GiB.

Backup and restore steps are in the deployment guide →

Browser extension

Save to your own instance in one click from the browser

The Chromium extension connects to your own instance. It saves pages, saves tab groups in one click, saves versioned web page snapshots, and turns posts from X, linux.do and similar sites into image cards. It works in Chrome, Edge, Brave and other Chromium-based browsers.

  1. Download markvault-extension-chrome.zip from the Browser page of your instance or from the latest release of the extension repository.
  2. Unzip it, open chrome://extensions/, turn on developer mode and choose "Load unpacked".
  3. Create an API key with suitable permissions in the MarkVault settings, then enter the instance URL and the key in the extension.
  4. If the extension's requests carry a cross-origin Origin, add chrome-extension://<extension-id> to CORS_ALLOWED_ORIGINS and restart the service.

The extension is maintained separately in the markvault-extension repository →

Mobile

Works in a phone browser too

The interface is responsive. On narrow screens a bottom navigation bar switches between bookmarks, tab groups and the agent.

Quick start

Deploy with Docker Compose

Requires Docker Engine 24+ and Docker Compose v2. The deployment targets one host and one container; multiple replicas sharing a data directory are not supported.

git clone https://github.com/xinmang/MarkVault.git
cd MarkVault
cp .env.example .env      # PowerShell: Copy-Item .env.example .env
mkdir -p data/go && sudo chown 1000:1000 data/go   # Linux only, before the first start
docker compose pull app
docker compose up -d --no-build --wait

Open http://localhost:8787 and register. curl http://localhost:8787/api/v1/health checks that the service is up.

  • The first account to register becomes the administrator, and registration is then closed automatically. The administrator can reopen it in the settings.
  • The container runs as UID/GID 1000:1000. On Linux, a newly created data directory must be handed to that user first, as shown above; otherwise the container cannot write to /data.
  • By default the port is bound to 127.0.0.1 only (APP_BIND). For public access, put a reverse proxy with HTTPS in front of it.
  • The default image is ghcr.io/xinmang/markvault:latest. For production, pin a version tag or image digest with MARKVAULT_IMAGE in .env.

Configuration, HTTPS, building from source, updates and troubleshooting are covered in the deployment guide.
